# MiniMax SDD 上下文模块

面向软件持续演进的规格驱动开发（SDD）上下文模块。

模块把业务工程的规格、代码符号与测试资料导入嵌入式 seekDB，按开发任务检索适用的规格、
需要修改的代码符号和用于验证的测试，组装成开发上下文交给 MiniMax 完成代码修改，并把任务状态
写入 PowerContext，供后续运行读取复用。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `sddctx/` | 上下文模块源码（CLI 入口 `python -m sddctx`） |
| `demo_shop/` | 样例业务工程，含待修改代码与测试 |
| `specs/` | SDD 规格文档（Markdown） |
| `docs/` | 运行说明、验证样例、技术使用记录、一页技术说明 |
| `artifacts/` | 运行产物：技术记录、日志、代码差异 |
| `verify/` | 验证样例脚本 |
